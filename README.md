# NovaCut — Mini Video Editor MVP

Professional, modular, AI-free/API-key-free video editor architecture.

### Included MVP
Import video/photo • Preview • Timeline • Thumbnails architecture • 9:16/16:9/1:1 • Undo/Redo • Auto-save • Trim • Split • Merge • Overlay • Text • 8 filters • Green-screen chroma key • Brush eraser/restore model • Opacity • 9 transition types • Audio/music • Volume • Audio trim/fade model • 0.5x–2x speed • 720p/1080p export architecture.

### Important
The web layer is a functional editor/state prototype. Production MP4 encoding, hardware acceleration, multi-track composition, reliable 1080p export and Android gallery access belong in the native layer. The project deliberately avoids AI/API services.

Open `index.html` for the web prototype. Open `android/` in Android Studio for native integration.
